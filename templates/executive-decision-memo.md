# Executive Decision Memo — uma página

Data / responsável / empresa / estágio / decisão pedida:

**Situação real (e fonte):**

**Por que agir agora? Custo de não agir:**

**Outcome humano, econômico ou de risco:**

**Fatos verificados, janela e denominador:**

**Hipótese principal / melhor explicação rival / contraprova barata:**

**Opções:** A / B / manter situação, com custos, upside/downside e reversibilidade.

**Recomendação:** por que esta opção vence sob hipóteses atuais?

**Dissent:** quem discordou, qual evidência sustenta?

**Alçada:** quem pode aprovar? ID e escopo de autorização quando efeito externo.

**Execução:** DRI / primeiro passo / prazo / dependências / métricas / fonte.

**Kill criteria / review date:**

**Resultado:** executado? em qual destino? prova? efeito real em quem? próximo gatilho?

Use STATUS: VERIFICADO / RELATADO / HIPÓTESE / SEM DADOS / SEM ACESSO / NÃO EXECUTADO / BLOQUEADO. PR ≠ deploy, cadastro ≠ cliente, teste ≠ pagamento.
